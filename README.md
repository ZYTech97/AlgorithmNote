## 二、算法笔记

### 1. [LeetCode 4. 寻找两个正序数组的中位数](LeetCode4_寻找两个正序数组的中位数.md)

**核心思想：二分查找划分边界。**

划分思路本身比较简单，难点在于**统一处理边界条件并保证算法正确性**。

1. **奇偶统一**：统一使用 `(m+n+1)//2` 确定划分位置，仅在返回中位数时区分奇偶。
2. **数组边界**：明确变量表示**划分位置，而非数组下标**；使用正负无穷大作为哨兵处理空区间。
3. **循环不变量**：利用条件的单调性进行二分查找，通过循环不变量证明不会遗漏目标位置，且最终结果不会被覆盖。

**可复用经验：** 明确变量含义，统一处理特殊情况，利用循环不变量证明算法正确性。

### 2. [LeetCode 128. 最长连续序列](LeetCode128_最长连续序列.md)

**核心思想：** 使用 `set` 加速成员查询，并仅从连续序列的最小元素开始向后检查，避免重复遍历。

1. **避免不必要的约束**：只需要保证整个算法最终得到正确结果，不必为每个中间步骤添加不必要的约束。
2. **先求解，再优化**：在有性能要求的问题上，先找到简单思路，再分析性能瓶颈并逐步优化。

### 3. [LeetCode 283. 移动零](LeetCode283_移动零.md)

**核心思想：** 使用双指针将非零元素按原顺序写入数组前部，再将剩余位置填零。

### 4. [LeetCode 42. 接雨水](LeetCode42_接雨水.md)

**核心思想：** 利用双指针维护左右两侧的最大高度，每次处理最大高度较小的一侧，逐步确定各位置的接水量。

1. **从确定性出发**：先解决能够确定结果的边界位置，再逐步扩展到未解决区域。
2. **利用问题性质推进**：根据接水量由左右最大高度的较小值决定这一性质，选择可以安全处理的一侧。

### 5. [LeetCode 3. 无重复字符的最长子串](LeetCode3_无重复字符的最长子串.md)

**核心思想：** 将问题分解为以不同位置为起点的子问题，再利用滑动窗口复用相邻子问题的计算结果，避免重复搜索。

1. **解空间分解**：按照某一维度划分候选解，分别求出局部最优解，再合并得到全局最优解。
2. **增量计算**：利用相邻子问题之间的关联，复用已有计算结果，避免重复计算。

### 6. [LeetCode 560. 和为 K 的子数组](LeetCode560_和为K的子数组.md)

**核心思想：** 通过**解空间分解**，将问题转化为统计每个起点或终点对应的合法子数组数量。按终点枚举更适合从左向右遍历：利用**前缀和与哈希表**维护历史信息，即可直接统计当前终点对应的合法起点，无需重复扫描后续元素，将时间复杂度从 $`O(n^2)`$ 优化至平均 $`O(n)`$。按起点枚举也可以通过反向遍历实现相同复杂度。

### 7. [LeetCode 438. 找到字符串中所有字母异位词](LeetCode438_找到字符串中所有字母异位词.md)

**核心思想：** 通过**解空间分解**，将问题转化为判断每个固定长度的子串是否为字母异位词。利用**滑动窗口**复用相邻子问题的字符频次，并通过 `diff` 记录频次不匹配的字符种类数，采用**新贡献减去旧贡献**的方式增量更新，将每次窗口判断优化为 $`O(1)`$。

### 8. [LeetCode 239. 滑动窗口最大值](LeetCode239_滑动窗口最大值.md)

**核心思想：** 通过**解空间分解**，将问题规约为求解每个固定长度窗口的最大值。利用**支配关系进行候选剪枝**：当新元素在数值和有效期上均不劣于较早元素时，可以安全淘汰较早元素。使用**单调队列**增量维护最大值候选，将时间复杂度从 $`O(nk)`$ 优化至 $`O(n)`$。

1. **支配关系与候选剪枝**：根据数值优势和位置优势，证明被支配的元素不可能再成为必须保留的最大值候选。
2. **增量维护**：通过队首删除过期元素、队尾淘汰被支配元素，实现窗口最大值的高效更新。
3. **循环不变量**：不变量只需在每轮完整迭代结束时成立即可。

### 9. [LeetCode 76. 最小覆盖子串](LeetCode76_最小覆盖子串.md)

**核心思想：** 通过**解空间分解**，将问题规约为寻找每个起点对应的最短合法子串。利用**覆盖条件的单调性**，通过滑动窗口使左右指针单向移动，避免枚举所有子串；使用字符需求表 `need` 和缺失计数 `missing` **增量维护**覆盖状态，将时间复杂度从朴素枚举的 $`O(n^2)`$ 级别优化至 $`O(|s|+|t|)`$。

### 10. [LeetCode 56. 合并区间](LeetCode56_合并区间.md)

**核心思想：** 排序 + 贪心。朴素解法中，当前合并区间的最终结果依赖于所有剩余区间，需要反复检查。通过按左端点排序建立单调性，使得当前区间一旦与下一个区间不重叠，就必然与所有后续区间不重叠，从而**实现局部解与剩余区间的解耦**。局部解可以安全确定，无需回溯，将反复扫描转化为一次线性扫描。一般性的算法思路是：通过引入某种结构（排序、单调性、边界约束等），将原本相互依赖的子问题转化为可以独立确定的局部问题。

### 11. [LeetCode 41. 缺失的第一个正数](LeetCode41_缺失的第一个正数.md)

**核心思想：原地标记。** 将问题规约为判断 `[1,n]` 中各整数是否存在。通过建立整数 `x` 与数组下标 `x-1` 的映射关系，利用数组元素的正负号记录存在性，并通过绝对值保留原始数值信息。**将原本需要额外哈希集合存储的信息编码到输入数组中**，实现时间复杂度 $`O(n)`$、额外空间复杂度 $`O(1)`$。

### 12. [LeetCode 142. 环形链表 II](LeetCode142_环形链表II.md)

**核心思想：快慢指针 + Floyd 算法。** 利用快慢指针的相对运动检测环，再定位环入口。首先将问题分解为检测环、计算环长、定位入口三个子问题：利用环的周期性，计算环长后让两个指针相距一圈并同步移动，即可找到入口。进一步分析首次相遇点蕴含的距离关系，发现可以直接从头节点和相遇点同步移动找到入口，省去显式计算环长的步骤。

**可复用经验：** 先通过问题分解和结构性质构造直观、易于证明的解法，再分析中间状态蕴含的信息，利用数学关系消除不必要的计算。

### 13. [LeetCode 19. 删除链表的倒数第 N 个结点](LeetCode19_删除链表的倒数第N个结点.md)

**核心思想：固定距离双指针。** 当目标位置与链表末尾存在固定距离关系时，可以通过双指针保持固定间距，利用一个指针的终止条件确定另一个指针的位置，避免显式计算链表长度。

### 14. [LeetCode 200. 岛屿数量](LeetCode200_岛屿数量.md)

**核心思想：DFS 连通分量计数。** 每次从未访问陆地启动 DFS，标记同一个岛屿中的所有陆地，DFS 的启动次数即岛屿数量。采用入栈即标记避免重复访问，并通过原地标记省去额外的访问数组。

## 三、通用算法设计思想

### 1. [IBP：基于状态和不变量驱动的算法设计](IBP_基于不变量驱动的算法设计.md)

**核心思想：从初始状态和目标状态出发，通过循环不变量设计状态迁移，再推导具体实现。**

以回文链表的反转操作为例，将算法设计分为四个步骤：

1. **状态定义**：明确初始状态与目标状态，提取不同情况的共同结构，统一边界条件。
2. **不变量设计**：根据合法中间状态推导状态变量、初始化和终止条件。
3. **状态迁移与实现**：先设计抽象状态迁移，再根据数据依赖推导具体操作顺序，必要时引入临时变量。
4. **正确性证明**：证明初始化、不变量保持、算法终止及目标达成。
